# Служебный ВК бот

Сборка и запуск

```sh
clear
mvn package -Dmaven.test.skip=true
set -a; . ./.env; set +a; java -jar ./target/vkbot-1.0.0.jar
```

## Переменные среды

| Название     | Описание                 | Пример    |
|--------------|--------------------------|-----------|
| VK_API_TOKEN | Ключ доступа сообщества  |           |
| VK_GROUP_ID  | Идентификатор сообщества | 228666999 |
